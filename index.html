Hover the screen to read the intensity at a point. Relative intensity, 1 = one beam at its peak

Every color is a mix of red, green and blue. The R, G, B numbers set the amplitude in each channel. 1 is a full-strength beam and there is no upper limit, so you can type any number, or inf. Within one channel, beams add as waves, so a 180° beam subtracts. Different channels never cancel; they add as light.
